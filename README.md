# 题库查询

基于 Excel 题库的查题、专题学习与刷题工具，支持电脑和手机 H5，无需数据库。需要 Node.js 20+，推荐 Node.js 22 或更新的受支持 LTS。

## 数据源

- `java题目.xls` — Java 题目
- `Linux题目..xls` — Linux 题目
- `sql题目..xls` — SQL 题目

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 将 Excel 转为 JSON（已有 data/questions.json 可跳过；更新 Excel 后执行）
npm run build

# 3. 启动服务
npm start
```

浏览器打开 **http://localhost:3456**

## 部署到其他电脑

1. 复制项目源码，包含 `server.js`、`lib/`、`public/`、`data/questions.json`、`package*.json` 和根目录三份 `*-tag知识点总结.md`；不要复制本机 `node_modules`。
2. 确保目标电脑已安装 Node.js 20+（推荐受支持的 LTS）。
3. 执行：

```bash
npm install
npm start
```

若只带了 `data/questions.json` 而没有 `.xls`，可直接 `npm start`，无需再 build。

## 功能

- 关键词搜索（题目、选项、答案、解析、标签）
- 按 Java / Linux / SQL 分类筛选
- 点击「查看答案」展开正确答案与解析，分页浏览
- 专题学习：Java 38、Linux 25、SQL 28 个专题，含代码和表格
- 按学科、专题、精确 tag 选择范围；支持顺序或随机练习
- 单选、多选、判断题提交判分；多选必须全部选对且不多选
- 提交前隐藏答案，提交后显示你的答案、题库原答案与解析
- 异常格式、题型矛盾、总结中已标记疑点的题仅供核对，不计入正确率
- 错题本自动记录最近答错的题，重练正确后移出，累计作答历史仍保留
- 浏览器本地保存练习顺序、位置、已选答案、提交结果及累计统计，刷新可继续
- 手机端默认收起筛选区，优先展示题目；整行点选、大按钮、代码和表格横向滚动

## 学习数据说明

- 原始 Excel 和 `data/questions.json` 不会被刷题操作修改；导入器只读取首个工作表。
- 专题从三份 Markdown 的正文与附录 tag 索引读取。一个 tag 可关联多个专题，页面展示关联题量，不同于文档中的主归类题量，也不等于逐题审定。
- 判分以题库原答案为准；已知疑题展示纠偏，但不代表题库所有答案已经审核。无法可靠识别的选项仍保留原文供核对。
- 修改题库 JSON 或总结后需重启服务；版本变化会使旧练习队列失效，累计统计和错题历史保留。
- 记录保存在 `localStorage`，统计为本浏览器全部学科的去重已练题量、累计提交正确率和最后一次答错的题量；核对题不计入统计。
- 没有账号和跨设备同步。不同域名、协议、端口、浏览器各自独立；清除网站数据或无痕窗口关闭可能丢失记录。服务端判分会接收本次选择，但不持久化学习记录。
- 同时打开多个标签页时，其他页修改记录会暂停当前页保存并提示刷新，避免相互覆盖。存储不可用、空间不足或数据损坏时有提示，不会冒充保存成功。

## 服务器部署与手机访问

在服务器项目目录安装并启动：

```bash
npm ci --omit=dev
NODE_ENV=production HOST=0.0.0.0 PORT=3456 npm start
```

此命令在前台运行。长期运行请使用服务器已有的 systemd、PM2 或容器进程管理，并设置重启策略；本次没有操作实际服务器。

- 默认监听 `0.0.0.0:3456`，可以经防火墙/安全组允许后访问 `http://服务器IP:3456`。
- 手机与本机处于同一局域网时，可访问 `http://电脑局域网IP:3456`；手机上的 `localhost` 指手机自己。
- 正式使用建议在 Nginx 等反向代理上配置域名和 HTTPS，将站点根路径 `/`（含 `/api/`）转发到 `http://127.0.0.1:3456`，并将 Node 绑定到 `HOST=127.0.0.1`，只对外开放代理端口。
- 页面和接口均使用同源路径，不硬编码 localhost，不依赖外部 CDN。当前按独立域名根路径部署，不支持未经配置直接挂到 `/question-lib/` 等子路径。
- 健康检查：`GET /api/health`。部署须保留 JSON 和三份总结文件；服务不需要原始 Excel，除非要重新导入。
- 页面及查题接口无登录限制；公网部署意味着访客可查询题库，这是个人练习工具，不是带防作弊机制的考试系统。如仅私人使用，请在反向代理限制访问。
- 推荐近期版本的 iOS Safari、Android Chrome 或微信内置浏览器。H5 仍需联网请求题目，不提供离线 PWA。

## 测试

```bash
npm test
```

使用 Node.js 内置测试工具，覆盖判分、题型与选项解析、全量专题映射、本地状态序列化及重复提交、API 参数校验、搜索回归和静态资源。手机布局已实现响应式规则；这些测试不代替真机浏览器验收。
